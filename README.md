# ZipService – Mobile App Prototype Concept

## 📱 Overview
**ZipService** is a community-driven mobile application that connects **customers** with **local small business owners** offering home-based services.  
It enables people to find trusted, nearby services within their own ZIP code area through a simple, location-based search.

---

## 👥 User Types
### 1. Customer
Individuals seeking local services without extensive browsing—ideal for newcomers or community-focused users.  
### 2. Small Business Owner
Stay-at-home parents, retirees, or skilled individuals who want to provide or showcase services from home.

---

## 🌟 Core Features
- **Search by ZIP Code:** Find services   
- **Two-Sided Marketplace:** Connects customers and local providers.  
- **User Profiles:**  
  - **Customers:** Browse, request, and book local services.  
  - **Small Business Owners:** Create detailed profiles with skills, pricing, and photos.  

---

## 🔄 User Flow

### 1. Onboarding & Authentication
- Welcome screen → Choose user type (*Customer* or *Business Owner*)  
- Sign up or log in (email, phone, or social login)  

### 2. Customer Flow
1. Enter ZIP code or auto-detect location  
2. Browse service categories  
3. View local business listings  
4. Check provider profiles (services, pricing, distance)  
5. Request or book a service  
6. Chat in-app for confirmation  

### 3. Business Owner Flow
1. Set up profile (photo, category, radius, pricing)  
2. Add service details and portfolio photos  
3. Manage bookings and availability  
4. Chat with customers  
5. View earnings and reviews  

### 4. Common Features
- Profile management  
- Notifications  
- Support / Help center  

---

## 🚀 MVP (Minimum Viable Product)
### Customer
1. Select *Customer*  
2. Enter ZIP code  
3. View nearby businesses (within 12 miles)  
4. Open basic business profiles  
5. Contact or request service (no payment integration)

### Business Owner
1. Select *Business Owner*  
2. Register / Login  
3. Add business details (name, category, ZIP, radius)  
4. Save profile → appear in search results
